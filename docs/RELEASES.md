# 版本说明（面向用户）

> 本文件是**公开发布**的版本说明 —— 每个版本一段，写清"这一版对你有什么变化"。
> GitHub Release 的正文就取自这里。
>
> 最新版本在最上面。格式参照 [Keep a Changelog](https://keepachangelog.com/)。
>
> **版本号只有一个真源**：仓库根 `gradle.properties` 的 `dshVersion`。
> 本文件里最新的那个版本号必须与它一致（`check-sync` 会校验）。

---

## 0.1.5-SNAPSHOT

> 本版把**界面皮肤对齐到 FCL 原版**、**给任务区补上"结果"**、并**把 API Key 完全交给 dsh**。
> 装之前请看「升级须知」——里面有一条和安全有关。

### 新增

- **任务区现在会说"结果"**：以前只显示"正在进行"，取消或失败之后那一行**瞬间消失**，
  用户看不到发生了什么。现在完成 / 失败 / 已取消都会留在列表里（保留最近 20 条），
  失败会带上原因；取消与停止也换成了两张不同的图标（原来长得一样）。
- **首次进界面时会提示去哪填 API Key** —— 只提示一次，之后不再打扰。

### 变更

- **API Key 完全由 dsh 自己管**：启动器不再保存、不再注入、也不再在启动前检查。
  - 表现上的变化：**没配 Key 也能启动**（以前会弹一个"尚未配置 API Key"的框挡住），
    起不来的是对话而不是整个实例。填 Key 的位置在 **dsh 界面里 → 设置 → 模型**。
  - **为什么必须这么改**：dsh 把"从启动环境继承来的 Key"视为最高优先级且**只读**，
    一旦启动器注进去，你在 dsh 的模型页里改 Key 会**直接被拒绝**（报错），
    等于在 App 里无论如何都改不掉。所以这不是取舍，是必须去掉。
- **实例详情里的"模型"设置行去掉了**：查证后确认那一项**从来没生效过** ——
  它对应的是一个并不被 dsh 读取的环境变量（同名常量在 dsh 里是另一个东西）。
  模型请到 **dsh 界面 → 设置 → 模型** 里选。
- **界面皮肤按 FCL 原版逐个对齐**（这一项看起来琐碎，但"塑料感"基本都来自它）：
  - **实例卡片在暗色下不再发白**（`auto_tint` 挂在错误的控件类上，一直静默失效）；
  - **图标不再全是默认黑色**（着色只对背景生效，以前挂在 `src` 上等于没上色）；
  - **切换亮暗主题后，已显示的行不再停在旧配色上**；
  - 日志页不再用自创的深色终端配色，改用与主题配套的一套，亮暗各一份；
  - 一票尺寸/留白/层级的对齐：页面左右留白、右面板内边距与标题字号、设置行的点击反馈、
    开关行高、组标题弱化、版本行的安装按钮改图标、任务区与其它列表统一。

### 修复

- **取消安装后"安装中"再也不消失**（要重启 App 才恢复）：取消时没有发出"结束"信号，
  界面永远等不到。现在取消有明确终态，且不会再闪一下"安装失败"。
- **"停止"可能停掉另一个实例**：任务行的停止动作没校验归属，从渲染到点击之间状态一变就停错。
- **运行时准备失败几乎看不到原因**（只在极短的竞态窗口里闪一帧）—— 现在会留在任务区。
- **安装失败记录无限增长**（内存缓慢泄漏）—— 失败后也做一次清理，原因不会丢。
- **安装失败时会告诉你真正的原因了**：以前不管什么原因，界面上只有一句
  「安装失败（详见日志）」。原因是**认不出新版本 npm 的报错格式**
  （npm 10 把错误行前缀从 `npm ERR!` 改成了 `npm error`），于是一条错误都没被收集到。
  现在会明确告诉你是什么问题、该怎么办 —— 例如「DNS 解析失败：当前网络无法解析域名，
  请换个网络或稍后重试」「网络超时，已下载的包有缓存不会从头再来」。
- **日志页滑到最底部会瞬间弹回最上面**（和"自动滚动"开关无关）：正文区域开了"可长按选中"
  （Android 的机制：每次刷新都会把光标位置重置到第 0 个字符，系统随后会把第 0 行滚回可见区）。
  代价是正文不能再长按选中 —— 「复制全部」按钮还在，功能没丢。
- **实例列表长按卡片会"破开"、露出底下的左滑菜单**：左滑菜单已**删除**；
  里面的两个动作（设置 / 删除）在「更多」里都有。
- **「更多」弹出菜单的风格与整个界面割裂**：换成了与设置页同款的 FCL 风格列表对话框。
- **"三个点"紧贴着"启动/重试"按钮、容易误触**：把它的可点区域从 20dp 撑到 40dp
  （与其它图标按钮一致），两个按钮的间距与垂直对齐也理了一遍。
- **装之前会检查磁盘空间**：以前只有"解压运行环境"那一步会检查，安装 dsh 不会。
  空间不够时直接告诉你「需要约 X，当前只剩 Y」，而不是下载到一半失败。

### 语言

- **语言选项从 12 项精简为 4 项**：跟随系统 / English / 简体中文 / **繁體中文**。
  其余几种既没有对应的翻译文件、也没有人校对，选进去只会得到一份半英半中的界面 ——
  比"没有这个选项"更糟。你原来选的如果是繁体（香港或台湾），升级后仍是繁体。
- **新增繁体中文**。
- **安装过程中显示的文字以前不会跟着语言变**（那段文字来自运行环境里的脚本，
  没有多语言机制）。现在脚本只报"阶段标识"，由 App 翻译 —— 英文界面下安装进度也是英文。
  运行环境准备、自检报告、通知栏、以及"停止原因"这些也一并跟着语言走了。

### 升级须知

- ⚠️ **与安全有关的一条**：旧版本会把 API Key **加密存在实例目录里**。本版不再读它，
  所以启动时会**自动删除**这两个遗留文件（`credentials.env` / `credentials.enc`）。
  你的 Key 不会因此丢失 —— 现在生效的是 dsh 自己那份（在 dsh 界面里填。
  第一次进界面会有提示告诉你去哪填）。
- 如果你以前"点了启动但被弹窗挡住"：现在不会了。没配 Key 也能起，进去填就行。
- 实例数据（名称、配置、已装版本）**不会丢**，就地升级即可。
- ⚠️ **首次启动会比平时久一点**：运行环境里的脚本换了版本，App 会重新解压一遍脚本
  （只有几 MB，不影响 rootfs 主体）。

## 0.1.4-SNAPSHOT

> 本版**大量改动界面结构与实例管理方式**。装之前请先看「升级须知」。

### 新增

- **实例详情页**：点实例列表里的任意一项即可进入，页内三个标签 ——
  **运行**（状态、启动/停止、打开界面、体积、路径、运行时自检）、
  **日志**（**只看这个实例自己的输出**，从启动到停止）、**配置**（名称、模型、profile、端口、重装、删除）。
- **每个实例有自己的日志**：实例的输出不再和别的东西混在一起；同时仍保留一份**应用日志**
  （解压 / 安装 / 凭据 / 运行时这些启动器自己打的行），在 **设置 → 日志** 里看。
  两份日志各自落盘：应用日志 `logs/runtime.log`，实例日志 `logs/instance-<实例>.log`。
- **返回键现在成体系**：从任意子页面按返回会**逐层退回**（详情页 → 列表 → 首页），
  而不是一路把 App 退掉。左侧菜单的返回按钮走的是同一条链。

### 变更

- **主菜单从 5 项精简为 3 项**：**实例 / 版本 / 设置**。
  - 「下载」改名「**版本**」—— 这一页本来就是"有哪些版本可以装"，名字与内容对齐。
  - 「管理」去掉：它一直是个空占位页，职责已由实例详情（进程）与版本页（版本）承担。
  - 「日志」去掉：实例日志进了实例详情，应用日志进了设置页的子页。
- **设置页**现在是三个子页：**启动器设置 / 日志 / 关于**。
  同时删掉了设置里那三条「版本下载 / 实例管理 / 运行日志」的跳转行 —— 左侧菜单已经有它们了，
  同一件事给两个入口只会让人犹豫点哪个。
- 实例列表的左右留白从 12dp 改为 **10dp**，与侧边菜单、右侧面板对齐。

### 修复

- **停止实例后 dsh 进程残留**：以前"停止"之后 rootfs 里的 dsh 进程可能还活着、继续占着端口，
  于是**下一次启动报 `EADDRINUSE`**（同一个实例第二次起不来）。本版从三个方向一起修：
  - 启动脚本把 dsh 进程的真实 pid 写出来，停止时**按 pid 精确终止**；
  - 停止信号换成 dsh 底座真正会响应的那个（以前发的信号它直接忽略，实际是靠强杀收尾，
    而强杀来不及清理子进程 —— 这才是残留的根因）；
  - 万一端口还是被占，**自动改用系统分配的端口**并写进日志，而不是丢一句"启动失败"。
- **"无法取得进程 pid"**：这条警告让"App 被杀之后仍在跑的实例"无法被识别和清理。
  根因是取值方式在 Android 上根本不成立（用了一个 Android 运行时不提供的方法）。
  现在补了一条从系统进程表读取的兜底路径。
- **首启准备页按返回会直接退出 App**：准备页是从启动画面直接进来的，任务栈里只有它自己，
  按返回等于把 App 关掉（用户以为崩了）。现在按返回是**回到桌面**，任务和正在跑的解压都留着，
  从最近任务点回来还能接着看。
- **从外壳进准备页再返回会叠出第二个主界面**：现在复用已有的主界面实例，不再新建。

### 升级须知

- **实例数据（名称、配置、已装版本）不会丢**，就地升级即可。
- 如果你曾经因为"停止后残留"而遇到过启动失败：**这一版修好了**，
  但建议升级后先重启一次手机（清掉之前残留的进程），再启动实例。

## 0.1.3-SNAPSHOT

> 本版**只更换运行时底座**（rootfs 瘦身），App 代码未改。

### 变更

APK 从 **311 MiB 降到 153 MiB** —— 把 rootfs 里运行时用不到的部分剔掉了：

- **GCC 开发环境**（`/usr/lib/gcc`、`/usr/include`、各 sanitizer 库、`lto-dump`）
- `/usr/lib/python3.11`
- perl 全家、`git-core`
- man / doc / info 文档
- 构建期缓存（`node-gyp` 头文件缓存、apt 索引与缓存）
- 非 UTF-8 字符集转换表 `gconv` 与 6 种大语种 locale

**保留**：`gcc`/`g++`/`make`/`pkg-config`/`python3`（各几 MB，作保险）、全部 `node_modules`
与 Node 运行时、apt/dpkg/openssl/ssh、`en` + `zh` + `ja` + `ko` 等 locale。

**依据**：dsh 的原生模块全部以 prebuild 形式分发（`node-pty` 自带 `linux-arm64` 二进制、
koffi / sharp / node-addon 同理），运行时不需要编译器。

### 数字

| | 0.1.2 | 0.1.3 |
|---|---|---|
| `rootfs.tar.xz` | 314,360,800 B | **148,637,136 B**（−52.7%） |
| 解压后 | 1436 MB | **862 MB** |
| APK | 311 MiB | **153 MiB** |
| 首次解压所需空闲空间 | ≥2 GB | **≥1.5 GB** |

### 升级须知

- 底座换了版本串，App 会**自动重新解压** rootfs（旧的会被替换）。
- 请预留 **≥1.5 GB** 空闲空间。
